# Awesome Hotel Technology

A curated list of hotel technology resources — PMS, channel managers, booking engines, open-source tools, and GST guides for hoteliers. PRs welcome.

## Open-Source PMS

- [QloApps](https://github.com/webkul/qloapps) — Free, open-source hotel management and reservation system: PMS, booking engine, hotel website (14k+ stars)
- [Kamra PMS](https://github.com/Kamra-PMS/kamra-pms) — Open-source hotel & short-term rental PMS: front desk, booking engine, folios with GST/tax billing, housekeeping, POS, WhatsApp
- [HAIP](https://github.com/TelivityAI/haip) — Open-source, API-first hotel PMS (TypeScript / Node.js / NestJS)
- [QloApps Hotel Booking](https://github.com/antonkarasbiz/qloapps-hotel-booking) — Open-source hotel PMS with booking engine, channel management, inventory, and payments
- [Noblesse Hotel PMS](https://github.com/TheAsilzade/noblesse-hotel-pms) — Full-stack hotel PMS built with NestJS, Next.js, Prisma and Redis
- [Hotel PMS (microservices)](https://github.com/Maleesha101/Hotel_PMS) — Cloud-ready hotel PMS built with microservices and REST APIs
- [PMS-CYNERZA](https://github.com/CYNERZA/PMS-CYNERZA) — Open-source hospitality PMS
- [hotel-pms](https://github.com/Khalidahmad0/hotel-pms) — Open-source hotel PMS project
- [birdnest_pms](https://github.com/juppyarsana/birdnest_pms) — Open-source hotel PMS project
- [hotel-management-software](https://github.com/NixndME/hotel-management-software) — Hotel management software project
- [Hotel Management System Software](https://github.com/codinsayan/Hotel-Management-System-Software) — Hotel management system project

## Channel Managers

- [Awesome Hospitality Channel Manager](https://github.com/ishandutta2007/Awesome-Hospitality-Channel-Manager) — Curated list of channel manager resources for hotels
- [Beds24 Platform SDK](https://github.com/Sleepy-beds/beds24-platform) — Typed, dependency-free SDK for the Beds24 channel manager API

## Booking Engines

- [Amadeus Hotel Booking (Django)](https://github.com/amadeus4dev/amadeus-hotel-booking-django) — Demo hotel booking engine using the Amadeus Self-Service API (Python / Django)
- [Free Hotel Booking Engine](https://github.com/TravelXML/Free-Hotel-Booking-Engine) — Hotel search and availability via the Openhotelier Partner API
